Context, Starclass Plugin(Star):    def __init__(self, context: Context):        super().__init__(context)    @filter.command("hello")    async def hello(self, event: AstrMessageEvent):        """Hello command."""        user_name = event.get_sender_name()        logger.info("hello command triggered")        yield event.plain_result(f"Hello, {user_name}!")    async def terminate(self):        """插件卸载或禁用时执行清理。"""```基本规则：- 插件类继承 `Star`。- 构造函数接收 `Context` 并调用 `super().__init__(context)`。- 事件处理器是异步方法。- 处理器前两个参数是 `self` 和 `event`。- 默认入口文件是 `main.py`。- 日志使用 `astrbot.api.logger`。## 4. 事件监听与消息发送常用过滤器和事件装饰器：- `@filter.command(...)`- `@filter.command_group(...)`- `@filter.keyword(...)`- `@filter.regex(...)`- `@filter.llm_tool(...)`- `@filter.event_message_type(...)`- `@filter.platform_adapter_type(...)`- `@filter.permission_type(...)`- `@filter.on_astrbot_loaded()`- `@filter.on_llm_request()`- `@filter.on_llm_response()`- `@filter.on_decorating_result()`- `@filter.after_message_sent()`普通处理器优先返回事件结果：```pythonyield event.plain_result("文本消息")yield event.image_result("path/or/url")yield event.chain_result(chain)```消息链示例：```pythonimport astrbot.api.message_components as Compchain = [    Comp.At(qq=event.get_sender_id()),    Comp.Plain("图片："),    Comp.Image.fromURL("https://example.com/image.jpg"),]yield event.chain_result(chain)```主动发送消息：```pythonfrom astrbot.api.event import MessageChainumo = event.unified_msg_originmessage_chain = `await event.send(...)`。- 使用 `event.stop_event()` 阻止后续处理器或默认 LLM 流程继续执行。旧接口迁移：```textawait ctx.send(...)       -> yield event.plain_result(...) / chain_result(...)await ctx.send_image(...) -> yield event.image_result(...)```## 5. 插件配置插件设置使用 `_conf_schema.json`。常用字段包括：- `type`- `description`- `hint`- `obvious_hint`- `default`- `options`- `labels`- `items`- `invisible`- `editor_mode`- `editor_language`- `editor_theme`- `_special`- `template_schema`- `templates`常用类型：```textstringtextintfloatboolobjectlistdicttemplate_listfile```读取注入配置：```pythonfrom astrbot.api import config```配置实体由 AstrBot 管理在：```textdata/config/<plugin_name>_config.json```官方文档中的版本要求：- `file` 类型：AstrBot `>= v4.13.0`- `template_list`：AstrBot `>= v4.10.4`- `_special` 的 provider、persona、knowledgebase 选择器：AstrBot `>= v4.0.0`## 6. AI、工具与 Agent当前推荐 API：```pythonprovider_id = await self.context.get_current_chat_provider_id(    umo=event.unified_msg_origin)response = await self.context.llm_generate(    chat_provider_id=provider_id,    prompt="请总结这段内容",)```可使用以下方式注册或运行工具：- `@filter.llm_tool(...)`- `self.context.add_llm_tools(...)`- `await self.context.tool_loop_agent(...)`装饰器工具示例：```python@filter.llm_tool(name="get_weather")async def get_weather(self, event: AstrMessageEvent, city: str):    """查询天气。    Args:        city(string): 城市名称。    """    return f"{city}：晴"```注意：- Docstring 必须包含 `Args:`。- 参数格式为 `name(type): description`。- 常用类型有 `string`、`number`、`object`、`boolean`、`array`。- `@filter.llm_tool` 不使用手写的 `parameters=...` 参数结构。- Docstring 格式错误可能导致工具参数 schema 为空。Agent 循环：```pythonresult = await self.context.tool_loop_agent(    event=event,    chat_provider_id=provider_id,    prompt="完成任务",    tools=tools,    max_steps=10,    tool_call_timeout=30,)```会话和人格管理入口：- `context.conversation_manager`- `context.persona_manager``on_llm_request` 中：- 长期稳定规则放入 `req.system_prompt`。- 当前轮动态内容放入 `req.extra_user_content_parts`。- 不应写入历史的临时内容使用 `.mark_as_temp()`，官方文档标记为 AstrBot `>= v4.24.0`。新代码不应默认使用：- `astrbot.ai.LLM`- `context.get_using_provider()`- `provider.text_chat(...)`- `context.llm_function_call(...)`- `context.register_llm_tool()`## 7. 数据存储小型插件状态优先使用 KV API，官方文档标记为 AstrBot `>= v4.9.2`：```pythonawait self.put_kv_data("greeted", True)greeted = await self.get_kv_data("greeted", False)await self.delete_kv_data("greeted")```大型文件存储到 AstrBot 数据目录：```pythonfrom pathlib import Pathfrom astrbot.core.utils.astrbot_path import get_astrbot_data_pathplugin_data_path = (    Path(get_astrbot_data_path()) / "plugin_data" / self.name)```存储规则：- 会话级状态可使用 `event.unified_msg_origin` 作为稳定键。- 持久用户数据不能放在插件源码目录。- 修改既有 SQLite 或 JSON 存储前，应考虑并发、备份和迁移。- 发布包不得包含用户数据库或真实用户数据。## 8. Plugin Pages目录结构：```textplugin/└── pages/    └── settings/        ├── index.html        ├── app.js        └── style.css```规则：- `pages/` 下每个一级目录表示一个页面。- AstrBot 加载 `pages/<page_name>/index.html`。- 后端通过 `context.register_web_api(...)` 注册接口。- 前端通过 `window.AstrBotPluginPage` 调用桥接 API。- 新代码优先使用 `astrbot.api.web` 中的 `request`、`json_response`、`error_response`、`file_response` 和 `stream_response`。- 页面资源使用相对路径。- SPA 页面优先使用 Hash 路由。- 所有输入必须在服务端验证。## 9. 国际化WebUI 国际化目录：
```text.astrbot-plugin/└── i18n/    ├── zh-CN.json    └── en-US.json```JSON 可包含：- `metadata.display_name`- `metadata.short_desc`- `metadata.desc`- `config.<field>.description`- `config.<field>.hint`- `config.<field>.labels`- `pages.<page_name>.title`- `pages.<page_name>.description``

HTML 转图片文本渲染：```pythonurl = await self.text_to_image(text)yield event.image_result(url)```HTML 和 Jinja2 模板渲染：```pythonurl = await self.html_render(    TMPL,    {"items": ["a", "b"]}, 使用 `@session_waiter(timeout=..., record_history_chains=...)` 注册等待器。- 回调内部通过 `await event.send(...)` 发送消息。- `controller.keep(...)` 继续会话。- `controller.stop()` 结束会话。- 调用等待器时捕获 `TimeoutError`。- 不希望流程继续进入默认处理时调用 `event.stop_event()`。- 自定义会话标识使用 `SessionFilter`。## 12. 插件内置 Skills插件可以携带 `skills/`：```textyour_plugin/└── skills/    ├── web-search-helper/    │   └── SKILL.md    └── report-writer/        └── SKILL.md```也可以只提供一个 Skill：```textyour_plugin/└── skills/    └── SKILL.md```AstrBot 加载插件后会将有效 Skill 注册到 Skill Manager。插件更新或卸载时，其提供的 Skills 也随插件一起更新或移除。## 13. 发布检查清单发布前检查：- `metadata.yaml` 存在，字段真实准确。- `main.py` 包含可加载的 Star 插件类。- `_conf_schema.json` 是有效 JSON。- `requirements.txt` 只包含实际使用的外部依赖。- `README.md` 说明安装、使用、配置和支持平台。- `repo`、`version`、`astrbot_version`、`support_platforms`、`social_link` 和 `tags` 已更新。- 发布包不包含缓存、虚拟环境、日志、用户数据库和测试产物。- 插件市场 ZIP 小于 **16MB**。- 异步处理器不执行阻塞式网络或文件操作。- 网络请求优先使用 `aiohttp` 或 `httpx`，而不是 `requests`。- 提交前在条件允许时使用 `ruff` 检查和格式化 Python 代码。## 14. 官方文档索引- [插件开发入门](https://docs.astrbot.app/dev/star/plugin-new.html)- [最小示例](https://docs.astrbot.app/dev/star/guides/simple.html)-
