# 项目概述：mjy1113451/astrbot_plugin_gm

## 1. 项目简介

`astrbot_plugin_gm` 是一个用于 AstrBot 的 QQ 群管理插件，提供插件管理员管理、禁言、踢人、撤回消息、设置群昵称、设置头衔、设置精华消息等常用群管能力。

## 2. 技术栈

- **主要语言**：Python 3.10+
- **插件框架**：AstrBot 插件体系
- **QQ 平台接口**：aiocqhttp / OneBot 相关 API
- **配置方式**：
  - `_conf_schema.json` 定义插件配置项
  - 支持通过 AstrBot 配置文件维护插件管理员、撤回提示、踢人后拒绝再入群等选项
- **许可证**：MIT License
- **运行场景**：AstrBot 机器人环境下的 QQ 群聊管理

### 核心文件说明

- **main.py**
  - 插件主逻辑文件。
  - 实现群管理命令，包括：
    - `/设管`、`/取管`
    - `/禁言`、`/解禁`
    - `/踢`
    - `/头衔`、`/取消头衔`
    - `/设管理`、`/取消管理`
    - `/设精`
    - `/设群昵称`、`/改昵称`
    - `/撤回`
    - `/禁我`
  - 同时负责权限判断、事件处理、API 调用兼容等逻辑。

- **metadata.yaml**
  - 插件元信息文件。
  - 通常用于声明插件名称、作者、描述、版本等信息，供 AstrBot 加载和展示。

- **_conf_schema.json**
  - 插件配置 Schema。
  - 定义可配置项，例如：
    - `show_recall_notice`：撤回后是否发送提示
    - `reject_re_add`：踢人后是否拒绝重新加群
    - `plugin_admins`：插件管理员 QQ 列表

- **README.md**
  - 项目说明文档。
  - 包含功能列表、安装方式、配置示例、权限说明和使用示例。

- **docs/**
  - 补充文档目录。
  - 当前包含问题解决方案文档，例如撤回命令相关问题说明。

- **.github/**
  - GitHub 项目配置目录。
  - 包含 Issue 模板等协作相关配置。

- **.sakura/**
  - 项目辅助配置或记忆目录。
  - 包含 `docs`、`memory`、`rules` 等子目录，可能用于自动化开发、AI 辅助或项目规则记录。

## 4. 开发约定

### 代码组织

- 插件逻辑集中在 `main.py` 中，适合小型 AstrBot 插件的单文件结构。
- 配置定义与业务逻辑分离：
  - 配置项由 `_conf_schema.json` 描述；
  - 运行逻辑在 `main.py` 中读取并使用配置。
- 插件元数据独立放置在 `metadata.yaml`，便于 AstrBot 识别和管理插件。

### 命令设计

- 命令统一使用中文斜杠指令，例如 `/禁言`、`/踢`、`/撤回`。
- 管理类命令通常要求“插件管理员”权限。
- 普通用户可使用部分自助命令，例如：
  - `/改昵称`
  - `/禁我`
- 部分命令依赖 QQ 官方群权限，例如禁言、踢人、设置管理员、设置精华消息等。

### 权限模型

项目采用两层权限设计：

1. **插件管理员**
   - 由配置项 `plugin_admins` 或命令 `/设管` 动态维护。
   - 群主默认具备插件管理员权限。
   - 可使用插件提供的大部分管理命令。

2. **QQ 群官方权限**
   - 某些操作需要机器人本身具有 QQ 群管理员或群主权限。
   - 例如禁言、踢人、撤回消息、设置群管理员等。

### 配置约定

- 布尔类配置使用明确语义命名，例如：
  - `show_recall_notice`
  - `reject_re_add`
- 管理员列表使用字符串 QQ 号数组保存，避免数字类型带来的精度或格式问题。
- 支持运行时通过命令动态调整插件管理员，提升群管理灵活性。

### 兼容性约定

- 项目面向 AstrBot 插件环境开发，并对不同 AstrBot 版本的 API 调用做了兼容适配。
- QQ 操作依赖底层平台 API，开发时需要注意机器人权限、平台接口返回值以及异常处理。
