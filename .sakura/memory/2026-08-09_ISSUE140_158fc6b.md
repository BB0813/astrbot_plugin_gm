### 仓库特有模式沉淀

**"单命令内权限路由分层"模式**正式沉淀为新模板:

- **触发场景**:某命令(举报/审批/操作类)需要根据被操作对象角色决定通知/响应路由,而不是简单的"统一通知所有管理员"
- **关键差异** vs "权限模型重构"模式(#130):后者是**全局权限模型替换**(`plugin_admins` → 群原生权限),前者是**单命令内通知路由分支**(保持现有权限模型,只改路由)
- **必查项**:①被操作者角色查询 API 差异(`get_group_member_info` 字段矩阵) ②通知路由配置语义(全局 vs 按群) ③角色缓存策略 ④"操作者不响应"文案友好性 ⑤"恶意互刷"防护 ⑥记录入库语义是否变化
- **必给标签**:`enhancement` + `command` + `group-management` + `notify`/`notification`(仓库新建) + `bot-role`/`sender-role` + `permission`(≥0.75) + `onebot`/`compatibility`(≥0.55) + `configuration`(0.65-0.75) + `needs-discussion`(0.75-0.85) + `needs-info`(≤0.30) + `breaking-change`(0.65-0.70,若扩展既有配置项语义)
