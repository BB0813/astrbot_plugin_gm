## 1. 分类与优先级准确性

**分类：`enhancement` —— 准确无误**

Issue 是新增命令而非修复现有功能，Issue 标题已明确标 `[enhancement]`。判断正确，无更优分类。

**优先级：`medium` —— 合理但可再校准**

支撑要素：
- 涉及跨适配器兼容性风险（非 v11 标准扩展 API）
- 权限模型决策待定（群主专属 vs 群管即可）
- 工作量可控（~2-3 天）

**潜在升级触发点**：若 `set_group_todo` 在用户主流适配器（go-cqhttp 旧版）不可用，本质上是一个"实现后大量用户无法使用"的功能。建议优先级章节补充："若用户所用适配器为不支持群待办的 go-cqhttp 旧版/Lagrange 部分版本，实际可用性显著降低 → 考虑维持 medium 但在 README 明确标注适配器矩阵"。

未升 `high` 是正确的——有明确兜底路径（提示不支持/降级为群公告）。
