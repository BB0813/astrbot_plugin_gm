2. OneBot API 对 `special_title=""` 的支持差异

   - 或不传 `special_title`
   - 或 `duration=-1`

3. 命令成功提示是否只依赖 API 返回值

这次最大问题是：

> `AI Issue analysis output could not be validated: SUGGESTED_MILESTONE must be on one line`
